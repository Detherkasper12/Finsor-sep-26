## 2. Supabase Dashboard Configuration

For each project (DEV and PROD):

1. Go to **Authentication > Providers > Google**
2. Enable the provider
3. Paste the **Client ID** and **Client Secret** from Google Cloud Console
4. The **Callback URL** is auto-generated by Supabase — copy it and add it to Google Cloud Console redirect URIs (see above)

### Client Secrets (NOT for client code)

- Client secrets go ONLY in Supabase Dashboard settings
- NEVER put client secrets in `.env` files, Dart code, or any client-side code
- The Flutter app uses only the **Client ID** (public)

## 3. Flutter App Wiring

The Google Web Client ID is stored in:
- `.env.dev` / `.env.prod` as `GOOGLE_WEB_CLIENT_ID`
- `web/index.html` as `<meta name="google-signin-client_id">` (required by google_sign_in_web)

The `lib/services/auth_service.dart` reads it from `Env.googleWebClientId` at runtime.

## 4. Troubleshooting

### "redirect_uri_mismatch"

The redirect URI in Google Cloud Console does not match the Supabase callback. Fix:
1. Copy the exact callback URL from Supabase Dashboard > Auth > Providers > Google
2. Add it to Google Cloud Console > Credentials > OAuth Client > Authorized redirect URIs
3. Wait 5 minutes for propagation

### "ClientId not set" on Web

Ensure `web/index.html` contains:
```html
<meta name="google-signin-client_id" content="YOUR_CLIENT_ID.apps.googleusercontent.com">
```

### 401 "Forbidden use of secret API key in browser"

You are using a `service_role` / `sb_secret` key instead of the `anon` public key. Fix:
1. Go to Supabase Dashboard > Settings > API
2. Copy the **anon public** key (starts with `eyJ...`)
3. Replace the value in `.env.dev` / `.env.prod` under `SUPABASE_ANON_KEY`
